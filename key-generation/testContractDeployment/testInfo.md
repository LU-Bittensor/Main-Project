# NECESSARY ITEMS FOR TESTING/DEPLOYMENT

### It is reccomended to create a new environemnt for testing for this concept - Ensure you have python installed in the new enviornment

- **Necessary Python Packages**
    - pip install web3 cryptography eth-abi boto3

- **Necessary System Packages (for linuxSetup.sh)**
    - sudo apt install openssl bash (For Debian/Ubuntu)
    - sudo dnf install openssl bash (For RHEL/Fedora)

- **Node.js packages (for local hardhat testing off-subtensor only)**
    - npm install --save-dev hardhat @nomicfoundation/hardhat-toolboxhh2
    - npm install --save-dev typescript

- **Python Version 3.10+ required**
